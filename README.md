# Personal Page | Resume & Portfolio

Bilingual resume and portfolio for Fausto Pastura. The site presents work in Salesforce and CRM consulting, custom business software, integrations, and workflow automation with or without AI.

**Live site:** [fausto-pastura-resume.vercel.app](https://fausto-pastura-resume.vercel.app/)

## Repository contents

- `resume-app/` — website source
- `cv/` — English and Spanish ATS-friendly resume files
- `git-profile/GITHUB_PROFILE_README.md` — source copy of the GitHub profile README

## Preview locally

From the repository root:

```bash
python3 -m http.server 4173 --directory resume-app
```

Open <http://127.0.0.1:4173>.
